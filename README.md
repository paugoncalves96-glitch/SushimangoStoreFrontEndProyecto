Este proyecto constituye la base de una página web en formato tienda online dedicada a la venta de productos de K-Pop.
En lugar de un título tradicional, opté por utilizar un logo diseñado por mí para darle una identidad más personal y coherente con la estética que imaginé.

La página combina tonos naranjas, amarillos y marrones, buscando transmitir calidez y simpatía.
Cuenta con un navegador principal y subtítulos centrados, junto con seis secciones organizadas con flexbox que funcionan como catálogo de venta.
Cada una incluye su imagen correspondiente, una breve descripción y un botón de compra.

Después del catálogo, coloqué dos videos como reseñas audiovisuales de los productos aunque no era un requerimento obligatorio. 
La sección de contacto presenta un formulario funcional creado con Formspree y un mapa de referencia, sobre una imagen que utilicé como fondo. 
Finalmente, el sitio cierra con un navegador en el pie de página, el cual, al igual que el del encabezado, es responsivo para permitir desplazarse fácilmente entre las distintas secciones,
tales como inicio, productos, contacto y reseñas.

Bajo el footer dejé oculta la tabla que hice como ejercicio en las primeras clases.
Todo el proyecto fue desarrollado con HTML y un CSS externo.
